统计口径与说明

统计已记录的 Agent 运行中模型返回的用量，包括子 Agent。缓存读取和写入属于输入，推理属于输出，不重复加入总量。未返回或未采集的用量不在统计内；这不是供应商账单。模型按运行配置归类，切换模型的运行可能混合用量。

机器人命令说明

在对话中可发送以下命令（支持中英文）：

通用

  • 帮助 help — 显示本帮助 | Show this help
  • 版本 version — 显示当前版本号 | Show version

身份与鉴权

  • 身份 whoami — 显示平台发送者、鉴权模式及当前实际 RBAC 身份 | Show effective identity
  • 绑定 <绑定码> bind <code> — 绑定当前平台账号到 RBAC 用户（仅逐用户绑定模式） | Bind RBAC user
  • 解绑 unbind — 解除当前平台账号绑定（仅逐用户绑定模式，需确认） | Unbind RBAC user

专用服务账号模式不接受“绑定/解绑”命令，仅允许机器人配置中白名单内的发送者。

对话

  • 列表 list — 列出所有对话标题与 ID | List conversations
  • 切换 <ID> switch <ID> — 指定对话继续 | Switch to conversation
  • 新对话 new — 开启新对话 | Start new conversation
  • 清空 clear — 清空当前上下文 | Clear context
  • 状态 status — 汇总当前对话、模式、角色与项目 | Show current status
  • 任务 task — 查看当前任务状态与运行时长 | Show current task
  • 重命名 <名称> rename <name> — 修改当前对话标题 | Rename conversation
  • 停止 stop — 中断当前任务 | Stop running task
  • 删除 <ID> delete <ID> — 删除指定对话（需确认） | Delete conversation

角色

  • 角色 roles — 列出所有可用角色 | List roles
  • 角色 <名> role <name> — 切换当前角色 | Switch role

模式

  • 模式 modes — 列出对话模式与当前选择 | List conversation modes
  • 模式 <名称> mode <name> — 切换对话模式 | Switch conversation mode

项目

  • 项目 projects — 列出所有项目 | List projects
  • 新建项目 <名称> new project <name> — 创建项目并绑定当前对话 | Create & bind project
  • 绑定项目 <ID或名称> bind project <ID|name> — 将当前对话绑定到项目 | Bind conversation
  • 解除项目 unbind project — 解除当前对话的项目绑定 | Unbind project

诊断与安全

  • 权限 permissions — 查看当前业务权限 | Show effective permissions
  • 诊断 doctor — 检查关键配置状态 | Check configuration status
  • 确认 confirm / 取消 cancel — 确认或取消高风险操作 | Confirm or cancel risky action

除以上命令外，直接输入内容将按绑定用户或服务账号的实时 RBAC 权限发送给 AI。Otherwise, text is sent to AI under the effective RBAC identity.
